Manual check, per browser

    
I can't sign in to your accounts, so these need a human. Run through them once in each browser you care about (Chrome, Safari, Firefox, Brave, plus a phone if you can). Checkboxes and table cells are just scratch space; nothing is saved.


    
Setup

    
    
      
  • Open this page from http://localhost:8000, not by double-clicking the file. YouTube refuses to play embeds with no referrer (error 153), which is what file:// sends.
    • 
      
  • In a separate tab of the same browser profile, sign in at open.spotify.com and youtube.com. Then reload this page.

What to expect (and why)

    
    
      
  • Both embeds only know who you are through cookies on spotify.com / youtube.com. Inside our page those count as third-party cookies. Chrome still allows them by default. Safari (Intelligent Tracking Prevention), Brave, and Firefox strict mode block them, so the embed acts logged out: Spotify falls back to 30 s previews and YouTube can show ads even to Premium users.
    • 
      
  • Spotify: the embed plays full tracks only when the listener is logged in to Spotify in that browser. Otherwise it plays 30 s previews. In-app webviews (Electron, Android WebView) are commonly stuck in preview mode.
    • 
      
  • YouTube: Premium's ad-free playback applies to embedded players when the viewer is signed in to their Premium account in that browser. Videos whose owner disabled embedding fail with error 101/150, which matters for some label music videos.
    • 
      
  • Neither API tells our code whether an ad is playing or which plan the user has. The best signal we have is Spotify's reported duration (~30 s means preview).
